## How these sources are used and cited

- **Cite, do not redistribute.** The repo holds extracted numbers (facts), each tied to a `refs/references.bib` key, and no PDFs,
  figures or copied text. Licences vary (many are CC BY-NC-ND; some are publisher-copyright), so keep PDFs out of the repo.
- **Every number in a figure or table must resolve to a `data/priors.yaml` row, and every row to a key below.**
- **Check licence terms before reusing any figure.** Digitised values are fine with citation; republished figures are not covered here.
